# Abel John Chiemerie — Portfolio

A personal portfolio for a Software Developer and Cybersecurity Enthusiast, built with Next.js, React and Tailwind CSS.

## Stack

- Next.js App Router
- JavaScript
- Tailwind CSS 4 with a custom CSS design system
- Lucide React
- CSS-based technology orbit
- Framer Motion, GSAP and Lenis dependencies available for future motion work

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Profile photograph

Place the supplied portrait at `public/images/profile/john.png`. The fixed, low-opacity monochrome portrait backdrop references that path.
